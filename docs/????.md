# 故障排查

## 1. Moonlight 连不上电脑

按顺序查：

1. **电脑醒着吗**：`诊断.cmd` 里 Sunshine 服务是否 Running；电脑是否按计划睡眠了（见使用说明第 6 节）。
2. **Tailscale 通吗**：`诊断.cmd` 的 tailscale 段有没有 100.x 地址；iPad 的 Tailscale 是否打开、是否同一账号。
3. **Sunshine 在跑吗**：浏览器打开 `https://127.0.0.1:47990`，用 `config\admin.txt` 里的账号密码登录。
4. **重启 Sunshine**：双击 `重启Sunshine.cmd`（若没有，运行 `Restart-Service SunshineService`，需管理员）。
5. **看日志**：`<安装目录>\Sunshine\config\sunshine.log` 最后几十行。

## 2. Tailscale 登录不上

- 校园网对 Tailscale 控制服务器（login.tailscale.com / controlplane.tailscale.com）可能不稳定，多试几次。
- 可尝试在 iPad 上先连手机热点登录 Tailscale，再切回校园网。
- 实在不行走直连兜底（使用说明第 9 节）：DuckDNS + 校园 IPv6，不依赖 Tailscale。

## 3. 配对失败 / PIN 无效

- PIN 是 iPad 上 Moonlight 显示的 4 位数字，必须在电脑浏览器 `https://127.0.0.1:47990` 的 **PIN** 页面输入。
- PIN 有时效，过期就重新在 Moonlight 里点一次配对。
- 确认 Web UI 账号密码正确（`config\admin.txt`）。

## 4. 黑屏 / 没画面

- **盖子合上了**：合盖会关内屏，Sunshine 可能采集不到画面。请把笔记本盖子保持打开，屏幕可以自动关闭。
- 显卡被切换：设备管理器确认 RTX 5080 正常；Sunshine 日志里应有 `Found HEVC encoder: hevc_nvenc`。
- 尝试把 Moonlight 码率降到 30 Mbps、分辨率降到 1920×1200。

## 5. 卡顿 / 延迟高

- 码率降到 30–40 Mbps；关闭 HDR；确认 iPad 连的是 5GHz/6GHz 的校园 Wi-Fi。
- 电脑同时跑大任务（下载、渲染）会抢编码/带宽。
- 看 Moonlight 统计：network latency 高 → 网络问题；host processing 高 → 电脑编码忙。

## 6. 文字发虚

- 码率提到 60–80 Mbps。
- Moonlight 选 2560×1600（或 iPad 原生分辨率）。
- 仍不满意可考虑换用 RustDesk/NoMachine 这类文字更锐利的客户端。

## 7. 中文输入

- 用 iPad 蓝牙键盘 + 电脑端微软拼音。
- 如果 iPad 输入法拦截，先把 iPad 输入法切到英文，用电脑输入法打字。
- 应急：在 iPad 上复制中文，到远程桌面里粘贴（Moonlight 支持剪贴板同步时）。

## 8. 睡眠后唤不醒 / 连不上

- 自动唤醒默认已关闭；如需定时唤醒，运行 `恢复自动唤醒.cmd`，再用 `诊断.cmd` 确认任务。
- 电源设置：合盖=不操作、AC 不自动睡眠（`安装.cmd` 已设）。
- 宿舍晚上断电的话，断电时段无法唤醒，这属于物理限制。
- 若 Modern Standby 导致唤醒异常，可改休眠（`powercfg /hibernate on` + 用 `shutdown /h` 代替睡眠）。

## 9. 安全检查

- `安全检查.cmd` 应显示：
  - `Sunshine` 规则 Disabled
  - `Campus-Remote TCP/UDP` 只允许 `100.64.0.0/10`（Tailscale）
  - `origin_web_ui_allowed = pc`
- 在 iPad 上关掉 Tailscale 访问电脑校园 IPv6 的 47989/47990，必须超时。
- 如果端口暴露，重新运行 `安装.cmd` 收紧防火墙。

## 10. 直连兜底（Tailscale 不可用）

1. 注册 DuckDNS 随机子域名，把子域名/token 填进 `config\config.json` 的 `direct`。
2. 双击 `更新DDNS.cmd`，确认返回 `OK`。
3. Moonlight 添加 `<子域名>.duckdns.org`。
4. 去新地点时，把该楼 Wi-Fi 详情的 IPv6 前 4 段发我，加到 `Campus-Remote` 防火墙白名单。
5. 注意：直连模式下视频流未加密，安全性低于 Tailscale。

## 11. 恢复/回滚

- 所有计划任务与防火墙规则可用 `卸载.cmd` 删除。
- 向日葵保持原样，可随时作为最后兜底。

## Android 装不上 / 连不上

- Moonlight：F-Droid（包名 `com.limelight`）或 GitHub Releases 的 `app-nonRoot-release.apk`。
- Tailscale：Google Play，或官方 APK 页 `https://pkgs.tailscale.com/stable/#android`；不要用来路不明的第三方市场。
- 如果配了 Tailscale ACL，把 Android 设备加进允许的 `src`。
- 部分 Android 设备只支持 H.264，Sunshine 会自动回退到 H.264。
