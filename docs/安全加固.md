# 安全加固说明

## 当前实际暴露面（2026-11-11 实测）

- Sunshine 安装包自带的“任意来源”防火墙规则：**已禁用**。
- 唯一放行的规则：`Campus-Remote TCP/UDP`，来源仅 `100.64.0.0/10`（Tailscale 私网）。
- Sunshine Web UI（47990）：不在放行列表，**只有本机能访问**；配置 `origin_web_ui_allowed = pc`。
- Tailscale 网络里只保留你自己的设备（例如电脑 + iPad），不要加入无关设备。
- 串流走 WireGuard 端到端加密，当前是直连（不走中继）。

**结论**：校园网、公网都扫不到 Moonlight 端口；别人要控制电脑，需要同时拿到你的 Tailscale 账号（或已解锁且已配对的 iPad）+ Windows 密码。风险低，但不是零。

## 建议你在 Tailscale 后台做的 3 件事

1. **Revoke 用过的 auth key**
   https://login.tailscale.com/admin/settings/keys → 找到刚才那个 key → Revoke。
   撤销不会断开已连接的电脑。

2. **开启 Device approval（新设备需审批）**
   https://login.tailscale.com/admin/settings/general → Device approval → 开启。
   以后任何人（哪怕拿到 key）加设备，都要你批准。

3. **给登录 Tailscale 的账号开 2FA**
   你用的是 Google / Microsoft / Apple / GitHub 哪个账号，就去那个账号开两步验证。这是最重要的一层。

## 可选：用 ACL 只允许 iPad 访问串流端口

Tailscale 后台 → Access controls，把策略改成：

```json
{
  "acls": [
    {
      "action": "accept",
      "src": ["<你的 iPad 设备名>"],
      "dst": ["msi:47984,47989,48010,47998-48002"]
    }
  ]
}
```

效果：即使以后 tailnet 里多了别的设备，也只有 iPad 能连电脑的 Moonlight 端口，其它一律拒绝。

> 改坏了也不影响你在电脑本机操作；把策略删掉恢复默认即可。

## iPad 丢了/被拿走怎么办

1. Tailscale 后台 → Machines → <你的 iPad 设备名> → **Remove**（立刻踢出网络）。
2. Sunshine Web UI → Clients → 移除已配对设备。
3. 改 Sunshine 管理员密码（Web UI → Password）。
4. 电脑本身如果也不放心：运行 `暂停远程访问.cmd`。

## 两个“安心开关”

- `暂停远程访问.cmd`：停掉 Tailscale + Sunshine，电脑彻底只能本机用。
- `恢复远程访问.cmd`：重新开启。

## 自己验证（推荐做一次）

1. iPad 上**关掉 Tailscale**。
2. 用 Safari 访问：
   - `http://[<电脑的校园 IPv6>]:47989`
   - `https://[<电脑的校园 IPv6>]:47990`
3. 两个都应该**超时/打不开**。打不开 = 校园网确实进不来。

## 还要注意的

- **Windows 密码**：远程会看到锁屏，登录要你的 Windows 密码，别设弱密码。
- **iPad 锁屏密码**：已配对的 iPad 是受信设备，锁屏是最后一道门。
- **更新**：Sunshine 和 Tailscale 保持更新；旧版本可能有已知漏洞。
- **物理安全**：宿舍门、电脑本身的安全，远程方案改变不了。
- **Sunshine 密码**：只在 `<安装目录>\config\admin.txt` 里，Web UI 只本机可访问；不放心可以在 Web UI 里改掉。
