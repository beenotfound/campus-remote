# Campus-Remote 使用说明

宿舍电脑远程串流套件（Sunshine + Moonlight + Tailscale），装在 `<安装目录>`。

---

## 1. 装了什么

| 组件 | 位置 | 作用 |
|---|---|---|
| Sunshine | `<安装目录>\Sunshine` | 电脑端被控/串流服务（NVENC 硬编） |
| Tailscale | `<安装目录>\Tailscale`（若装到 C 盘会注明） | 私有网络，免公网 IP、免 DDNS、全程加密 |
| 本套件 | `<安装目录>` | 安装/诊断/配对/唤醒/安全检查脚本 |
| 向日葵 | 原位置 | 保留作最后兜底，不动它 |

Sunshine 配置：`<安装目录>\Sunshine\config\sunshine.conf`
- `origin_web_ui_allowed = pc`：Web UI 只允许本机访问
- `upnp = false`
- 音频开启，编码器自动选 NVENC（HEVC/AV1）

---

## 2. iPad 端准备（一次性）

1. **Tailscale**：用你的非国区 Apple ID 在 App Store 安装 Tailscale（免费）。
2. **Moonlight**：国区 App Store 搜 “Moonlight Game Streaming” 安装（免费）。
3. iPad 连上 Wi-Fi（校园网/家里都可以）。
4. 打开 iPad 的 Tailscale，用**和电脑相同的账号**登录，打开开关。
   - 登录方式：Google / Microsoft / Apple / GitHub 邮箱等，任选一个；电脑端用同一个。
5. 记下电脑的 Tailscale 地址：在电脑上双击 `诊断.cmd`，看 `tailscale` 段的 `100.x.y.z`。

---

## 3. 电脑端登录 Tailscale（一次性）

1. 双击 `登录Tailscale.cmd`。
2. 窗口会打印一个 `https://login.tailscale.com/...` 链接；在电脑浏览器打开并登录。
3. 登录完成后窗口会显示 `tailscale status`，能看到电脑自己的 100.x 地址。
4. 如果链接没自动出现，运行 `诊断.cmd` 看状态；或右键任务栏 Tailscale 图标登录。

---

## 4. 配对 Moonlight

1. 双击 `配对.cmd`，会：
   - 打印 Sunshine Web UI 的账号密码（也在 `config\admin.txt`）；
   - 打开 `https://127.0.0.1:47990` 和 PIN 页面。
2. iPad 打开 Moonlight → “+” → 添加主机，填电脑的 `100.x.y.z`。
3. iPad 会显示 4 位 PIN；在电脑浏览器里登录 Web UI，点 **PIN**，输入这 4 位。
4. 回到 Moonlight，选择 **Desktop** 开始串流。

### Moonlight 推荐设置
- 分辨率：2560×1600（列表没有就 1920×1200 或 “Native”）
- 帧率：60 FPS（iPad Pro 可试 120）
- 码率：40–60 Mbps 起步；文字发虚可升到 60–80
- 视频编码：HEVC
- HDR：关闭
- 音频：开启
- 鼠标：连接蓝牙鼠标后，在 Moonlight 里切换鼠标/触控模式

---

## 5. 日常使用流程

1. iPad 连上 Wi-Fi，打开 Tailscale 开关。
2. 打开 Moonlight，点电脑 → Desktop。
3. 用完直接退出串流；电脑按计划自动睡眠。

---

## 6. 睡眠/唤醒

**默认已关闭自动唤醒和自动睡眠**（按你的要求）。电脑不会自己醒，也不会自己睡。

- 需要定时唤醒/睡眠时：双击 **`恢复自动唤醒.cmd`**（按 `config\config.json` 里的时间）。
- 想再次关闭：双击 **`关闭自动唤醒.cmd`**。
- 手动控制：开始菜单 → 电源 → 睡眠/关机；需要远程时保持电脑开着、插电、盖子打开。
- 电脑睡眠/关机后 iPad 连不上，需要先在本机把它唤醒/开机。
- 注意：合盖会关内屏，串流可能黑屏；远程使用期间盖子保持打开。

---

## 7. 安全检查（建议做一次）

双击 `安全检查.cmd`：
1. 确认 `Sunshine` 规则是 Disabled，`Campus-Remote TCP/UDP` 只允许 `100.64.0.0/10`（Tailscale）。
2. 在 iPad 上**关掉 Tailscale**，用 Safari 访问：
   - `http://[电脑的校园IPv6]:47989` → 应超时/拒绝
   - `https://[电脑的校园IPv6]:47990` → 应超时/拒绝
   如果这两个能打开，说明防火墙没收紧，重新运行 `安装.cmd`。
3. 开着 Tailscale 时 Moonlight 能正常连。

---

## 8. 常见问题

**Moonlight 连不上**
- 先看 `诊断.cmd`：Sunshine 服务是否 Running、Tailscale 是否有 100.x。
- iPad 的 Tailscale 是否打开、是否同一账号。
- 电脑是否在睡眠（对照第 6 节时间表）。
- 重启 Sunshine：`重启Sunshine.cmd` 或 `Restart-Service SunshineService`（管理员）。

**黑屏 / 没画面**
- 电脑盖子是否合上了；打开盖子。
- 显卡是否被切换：设备管理器里 RTX 5080 正常。
- 码率太高导致卡顿：降到 30–40 Mbps。

**中文输入**
- 建议用 iPad 蓝牙键盘 + 电脑端微软拼音。
- 如果 iPad 输入法拦截，切到英文输入，用电脑输入法打字。

**Tailscale 登录不上**
- 校园网对 Tailscale 控制服务器可能不稳定；多试几次。
- 实在不行用直连兜底：见第 9 节。

---

## 9. 直连兜底（Tailscale 不可用时）

1. 去 https://www.duckdns.org 注册一个**随机**子域名，拿到 token。
2. 把子域名/token 填进 `config\config.json` 的 `direct` 段。
3. 双击 `更新DDNS.cmd`（或运行 `scripts\ddns.ps1 -InstallTask`）注册每 5 分钟更新。
4. Moonlight 添加主机时填 `<子域名>.duckdns.org`。
5. 运行 `允许校园直连.cmd`，把 `config\config.json` 里 `direct.allowedPrefixes` 列的楼栋 /64 放进防火墙。
   默认只放行 Tailscale；去新楼栋时，把该楼 Wi-Fi 详情的 IPv6 前 4 段加进这个列表，再运行一次 `允许校园直连.cmd`。

---

## 10. 卸载

双击 `卸载.cmd`：删除计划任务、防火墙规则、Sunshine、Tailscale。`-RemoveData` 会连 `<安装目录>` 一起删。向日葵不受影响。
